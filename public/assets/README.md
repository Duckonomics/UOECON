# Public visual assets

Place only author-approved, public figures or figure crops here.

- Use a descriptive filename such as `figure-2-panel-a.png`.
- Add meaningful alternative text and a checked caption in `public/site-config.js` or `src/paper-config.js`.
- Confirm that labels remain readable on a phone.
- Do not include restricted data, confidential screenshots, unpublished results, or identifying metadata.
- When showing only selected table rows, panels, or columns, label the excerpt clearly and preserve units and notes.
